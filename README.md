## 📝 Project Overview

This is a simple **Rock-Paper-Scissors game** built using Python.  
The user plays against the computer, which makes random choices. The program then determines the winner based on classic game rules.

This project is great for beginners to practice **logic building and conditional statements**.

## ⚙️ How It Works

### 🎲 Choices Mapping
The game uses a dictionary:

0 → rock
1 → paper
2 → scissors


---

### 🤖 Computer Choice
- Computer randomly selects a number between 0–2  
- This corresponds to rock, paper, or scissors  

---

### 👤 User Input
- User enters:

0 (rock), 1 (paper), 2 (scissors)


---

### 🏆 Winner Logic

- Same choice → Tie  
- Rock beats Scissors  
- Scissors beats Paper  
- Paper beats Rock
